# Burrow3D — Instructions for AI Agents

Проект без сборки: три статических файла в корне, всё остальное — документация и скриншоты.
Правки вносятся прямо в `index.html` / `biomes.js` / `maps.js`, никаких зависимостей ставить не нужно.

## Commands

| Задача | Команда |
|--------|---------|
| Запуск | открыть `index.html` в браузере (double-click, работает по `file://`) |
| Запуск по HTTP | `python -m http.server 8801 --bind 127.0.0.1` в корне, затем `http://127.0.0.1:8801/` |
| Синтаксис | `node --check biomes.js` и `node --check maps.js` |
| Проверка в браузере | открыть страницу, консоль должна быть пустой, все 7 наборов переключаются без ошибок |
| Сборка / линт / тесты | **отсутствуют** — проект их не имеет, не придумывай |

`index.html` — единый модуль, синтаксис проверяется только загрузкой в браузере.
После правок всегда проверяй консоль: ошибки видны в DevTools, `window.BURROW` даёт доступ к сцене из консоли.

## Conventions

- **Стиль** — как в существующем коде: 2 пробела, `const`/`let`, стрелки, без `var`.
- **Комментарии** — только там, где объясняют *почему*, а не *что*. Грабли three.js описаны в коде.
- **Порядок в `biomes.js`** — `name`, `note`, `sky`, `water`, `relief`, `ground`, `scatter`.
- **Новый набор оформления** — скопировать существующий блок в `BIOMES` и поменять значения.
  Движок подстраивается сам: нигде не нужно регистрировать объект заново.
- **Новый объект** — добавить в `BUILDERS` в `index.html`. Части объединяй через
  `mergeAll([...])`, чтобы не плодить `InstancedMesh`. Части без `id` нельзя перекрасить из набора —
  дай каждой `id`.
- **Русский язык** в комментариях, UI и документации. Идентификаторы — английский.
- **Цвета** — только `setHex(0x..., THREE.SRGBColorSpace)`. Значение `0x...` без указания
  цветового пространства читается как linear и будет темнее в 2.2 раза (см. грабли в `DECISIONS.md`).

## Грабли, которые нельзя повторить

1. **`InstancedMesh.setColorAt` без `vertexColors: true` не работает** вообще: `color_fragment`
   применяет `vColor` только под `USE_COLOR`. А r169 **удалил** `Material.defaultAttributeValues`,
   поэтому без явного белого атрибута `color` на геометрии он читается как (0,0,0) — объекты
   становятся чёрными. Отсюда хелпер `whiteColors()`.
2. **`Color.setHSL` по умолчанию не конвертирует** в рабочее пространство (в отличие от `setHex`).
   `instanceColor` трактуется как linear — sRGB-lightness приходится задавать явно.
3. **Байты в DataTexture пишутся в sRGB.** Считаем цвет в linear, потом
   `convertLinearToSRGB()` и только потом `* 255`, иначе двойной encode и земля уходит в чёрный.
4. **`fbm` возвращает узкий диапазон** (усреднение октав сжимает значения к 0.5). Для гор нужен
   отдельный `fbmRidged` — иначе `1-|2n-1|` даёт почти константу и получается плато.
5. **Индекс клетки умножается на `CELL`**: `-WORLD/2 + (cx + rnd()) * CELL`. Забыли `* CELL` —
   вся растительность сжалась в один квадрант карты.
6. **Расстановка и текстура должны совпадать по оси Z.** UV: `v = (z + PZ/2) / PZ`, без `1 -`.

## Do NOT touch

- `docs/*.png` удалены, скриншоты — `.jpg` (вес репозитория). Перегенерировать скриншоты — только
  если меняется вид; формат jpeg, качество 84, размер 1600×1000.
- `LICENSE` — Apache-2.0, текст не редактировать.
- Встроенную карту `burrow-01` в `maps.js` — это исходная карта пользователя, 1:1 из
  `burrow-01(2).json`. Не «выравнивать» и не переформатировать строки.

## Documentation rules

- После работы — обнови `docs/CONTEXT.md`: статус, открытые проблемы, журнал.
- Архитектурное решение — запись в `docs/DECISIONS.md` (append-only).
- Новый `.md` в `docs/` — только с разрешения пользователя.
- Переиспользуемые знания (грабли three.js, приёмы рендера) — в
  `D:\GitHub\knowledge\` с записью в `knowledge/README.md`.
- Коммиты — прямо в `main`, по-русски или по-английски, императив, ≤72 символа в заголовке.
